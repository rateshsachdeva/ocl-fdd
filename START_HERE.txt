OCL FDD - START HERE
====================

1. Use an approved output from fdd-data-preparation.
2. Run:
       python run_all.py --data-prep-output <path-to-output/latest>
   If the repos are side-by-side, try:
       python run_all.py
3. Follow the state printed by the runner:
   - AWAITING_SEMANTIC_HANDOFF
   - AWAITING_JUDGMENT_REVIEW
   - AWAITING_CONTROL_ALIGNMENT
   - DATABOOK_READY
4. Do not bypass failed controls or invent balancing values.
5. Final Part 1 output is output/OCL_Databook.xlsx.

For an AI coding host, read SKILL.md and src/ocl_agent/llm/README.md before changing config.
