OCL FDD - START HERE
====================

1. Put the raw client Excel files in:
       references/source/

2. One-time GitHub Copilot CLI setup:
       copilot --version
       copilot login --web-flow

   Complete the GitHub sign-in once. If Copilot is provided through an organization
   or enterprise, the Copilot CLI policy must be enabled by that organization.

3. From the repository root run:
       python run_all.py

4. The workflow is:
       raw Excel
         -> full fdd-data-preparation
            -> Python profiling
            -> GitHub Copilot dataset understanding + Processing Plan
            -> Python deterministic execution + completeness + lineage
         -> published standardized long/flat data
         -> OCL semantic interpretation
         -> OCL judgments + hard controls
         -> Python metrics
         -> GitHub Copilot FDD-partner Deal Issues + Key Findings + Q&A
         -> styling + final QA + PPT

5. Principal output when complete:
       output/OCL_Databook.xlsx

6. Secondary output:
       output/OCL_Report.pptx

AI CHECKPOINTS
--------------
`python run_all.py` uses GitHub Copilot CLI as the automatic AI host.

The Python financial core does not call a model API. Copilot is used only for the
contextual AI reasoning artifacts requested by the workflow. Python continues to
own source values, calculations, reconciliations, controls and rendering.

A Copilot checkpoint counts as complete only when the exact required artifact(s)
were actually created or updated. Authentication/install failures therefore stop
safely instead of advancing or looping.

If Copilot reports "No authentication information found", run:

       copilot login --web-flow

then rerun:

       python run_all.py

If you deliberately want an already-open interactive agent session to complete an
AI checkpoint instead of spawning Copilot CLI, use:

       python run_all.py --ai-host external

Do not commit client source files. references/source/ is intentionally ignored by Git.
Do not bypass failed controls or create balancing plugs.
