OCL FDD - START HERE
====================

1. Put the raw client Excel files in:
       references/source/

2. Run from the repository root:
       python run_all.py

3. The skill will internally:
       raw files
         -> fdd-data-preparation
         -> standardized data + lineage
         -> OCL scope/mapping/controls
         -> databook
         -> analysis
         -> management questions
         -> styling
         -> final QA

4. Principal output:
       output/OCL_Databook.xlsx

5. Secondary output:
       output/OCL_Report.pptx

Do not commit client source files. references/source/ is intentionally ignored by Git.
Do not bypass failed controls or create balancing plugs.

For the detailed contract, read SKILL.md.
